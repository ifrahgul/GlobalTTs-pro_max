# GlobalTTs-Pro Max

AI-powered multilingual text-to-speech application developed using Python.

## Features
- Multilingual voice generation
- Text-to-speech conversion
- User-friendly interface
- AI-powered speech processing

## Technologies Used
- Python
- TTS Libraries
- AI/ML Concepts
## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Ifrahgul-lang/GlobalTTs-pro_max.git
```

### 2. Open Project Folder

```bash
cd GlobalTTs-pro_max
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment (PowerShell)

```powershell
.\venv\Scripts\Activate
```

### 5. Install Required Packages

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
streamlit run app.py
```
